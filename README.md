# zhanghaoran.github.io
ForgeOS project

首次访问默认显示英文。导航栏的 `CN / ENG` 按钮显示当前语言，点击后切换；浏览器会记住选择。语言和主题分别保存，原有动画与特效保持不变。

时间规划、学习知识库、智能体账号页各有一张首次使用指引，支持开始使用、跳过、关闭与 Esc。显示后即以独立的 `forgeos:onboarding:<模块>` 存储项记住状态，刷新或再次进入不会重复弹出，也不会修改任务或笔记。指引跟随语言和主题，不使用持续动画或背景模糊；本机存储不可用时尝试会话存储。清除网站数据或更换浏览器后会再次显示。运行 `node tests/onboarding-browser.cjs` 检查独立记忆、关闭操作、响应式布局与存储降级。

指引使用模块专属的轻量示意图、三色图标步骤卡片与简短文案；窄屏自动改为纵向卡片，底部操作保持可见。可通过「使用指引 / Quick guide」手动重看：规划及账号页在标题旁，知识库在左侧栏底部；重看不会重置首次访问记录。

静态内容的英文译文放在 `index.html` 的 `data-i18n-en` 等属性中；动态提示、打字机和终端文案由 `assets/js/i18n.js` 管理。

英文模式通过 `--text-scale` 将小字号放大 6%，中文字号和大标题保持原设置。特效引擎缓存浅色静态网格，静止时停止重复绘制；夜色星网保留全部粒子与连线，鼠标视差和卡片倾斜按需更新。运行 `node tests/fx.cjs` 检查粒子连线完整性、画布分辨率、休眠与唤醒、涟漪拖尾和主题切换。

鼠标性能优化保留全部特效、粒子数量和原画布分辨率：视差改为直接移动目标层，光标缓动按实际时间推进，卡片缓存几何信息并缩小光泽样式的更新范围。同机核显对比、原因及复现步骤见 [性能检查记录](docs/PERFORMANCE.md)。

本机安装 Chrome 和 Node.js 22 或更新版本后，可运行 `node tests/language.cjs` 检查语言切换、窄屏布局、主题兼容、动画和存储降级。Chrome 安装在其他位置时，用 `CHROME_PATH` 指定可执行文件。

首页的代码工坊、灵感核心和系统面板尚未开放，使用灰色无光卡片与状态标识，不启用悬停发光或倾斜；时间规划及知识库入口保持点亮。文档中心与 CLI 的筹备入口也使用无光样式，点击可查看状态提示。

内容默认可见，入场效果只在进入视口时播放；脚本加载失败后会自动退出启动遮罩。测试还覆盖锚点跳转、快速滚动、缺少 IntersectionObserver、禁用 JavaScript 和点击区域尺寸。

分享图源文件为 `assets/images/social-card.svg`，发布使用同目录下的 PNG。执行 `node tests/language.cjs --render-social` 可重新生成 1200×630 分享图并运行检查。

动态时间规划原型位于 `/planner/`，可从首页“动态时间规划”卡片进入。支持自然语言规则识别、任务编辑、固定安排、七天排程建议、冲突提示、用户确认、延长任务后重排，以及本机浏览器保存。该本地原型尚未连接 AI 智能体；中文字体回退到系统中文字体，英文使用 Calibri（如果已安装）。运行 `node tests/planner.cjs` 检查排程规则。

Schedule 主页面 `/planner/` 的「有什么待办？」已接入 Google 日历：在同一页面授权、选择日历，填写开始时间和预计时长，点击「添加任务并同步日历」即可同时加入待办和真实日历。默认勾选同步，取消可仅保存本地；失败保留草稿，重试避免重复创建。旧 `/planner/calendar.html` 保留为独立入口。配置 Google OAuth 后通过本地服务连接标准 Google Calendar API，个人 Google 账号即可使用，无需 Workspace 订阅或 MCP 预览资格。录入指定时间、事件和备注；重叠也会创建，并把新事件在 Google 日历中标红。此功能不自动调整时间，也未连接真实 AI 模型。运行 `npm ci`、`npm start`，打开 `http://127.0.0.1:8787/planner/`；首次配置见 [Google Calendar 接入说明](docs/GOOGLE_CALENDAR_MCP.md)。当前测试使用模拟日历，真实 Google 授权尚待配置验证。

本地运行 `python -m http.server 5500 --bind 127.0.0.1`，打开 `http://127.0.0.1:5500/planner/` 即可体验。也可使用 VS Code 的“预览网页”任务。

页面设计样板位于 `/planner/template.html`，采用深蓝、冰蓝和青色的工作台布局，支持中英文、明暗主题、日期切换与示例任务勾选。样板使用独立的展示数据，不读取或修改真实规划任务，也不保存示例操作。入口位于规划页标题旁的辅助操作区，与“试用示例任务”放在一起。

智能体账号页位于 `/planner/agent.html`，工作台及样板页提供“选择默认智能体”和“登录智能体”两个入口。前端仅展示 Codex、Claude、Gemini、DeepSeek V4、Kimi；支持演示登录、从已登录账号中保存或切换默认智能体、取消默认及退出。状态保存在独立的 `forgeos:agent-accounts:v1` 本机存储项中。登录不会自动设置默认，退出默认账号会清除默认选择。当前为纯前端演示，无需密码或 API Key，未接入真实授权或智能体调用，Schedule 仍使用本地规则。旧服务配置不作为登录状态读取。

学习知识库位于 `/knowledge/`，采用左侧历史会话、右侧对话内容和底部输入框的布局。支持新建、切换、搜索、重命名及删除对话，Enter 发送、Shift + Enter 换行；手机端历史记录为抽屉。首次使用没有预置科目、笔记或会话，由用户自行添加。科目和文档在弹窗内管理，支持 Markdown/TXT 导入、文档说明、阅读与回忆复习、学习记录及 Markdown 导出。目前尚未连接 Obsidian 或 AI；发送消息会检索本地笔记，并明确标注结果来源。笔记保存在 `forgeos:knowledge:v1`，会话独立保存在 `forgeos:knowledge-chats:v1`，删除会话不会删除文档；切换会话时保留未发送的草稿，草稿在刷新后不保留。单份文档限制为 200 KB、50,000 字，最多 50 个科目、200 份笔记及 100 个会话，每个会话最多 100 轮。运行 `node tests/knowledge-browser.cjs` 检查聊天、本地保存、中英文主题及响应式布局。

独立页面的后续安排见 [页面规划](docs/SITE_PLAN.md)。当前 `sitemap.xml` 收录已存在的首页、时间规划页和学习知识库；修改域名时请同步更新 CNAME、canonical、分享地址、结构化数据、robots.txt 和 sitemap.xml。

# 输入与输出约定

供网站后端或直接调用此技能的 Agent 使用。路径由调用方提供，不绑定老师原始文件夹或某个模型。

## 输入

| 输入 | 要求 |
| --- | --- |
| 资料文件 | 明确指定一个或多个 PDF 或 Markdown 文件；可同时提供同一资料的两种格式 |
| 输出目录 | 明确指定本次知识库的根目录；原始资料及技能目录不作为输出目录 |
| 处理范围 | 可指定章节、Unit 或页码；未限定时按原书顺序分批处理 |
| 已有知识库 | 更新时读取输出目录内已有笔记、目录与日志；初次导入可以为空 |
| 页码映射 | 如解析程序已生成页码与文本对应关系，一并提供；没有映射时不承诺 PDF 页级定位 |

只处理指定资料；不因附近存在其他 PDF 而自动导入。原始 PDF、原始 Markdown、老师的规则及范本保持只读。新笔记、目录与日志写入指定输出目录；派生的解析文本写入调用方指定的工作目录。

## 输出目录

```text
输出目录/
├── 知识库/
│   ├── 主题/
│   ├── 国家与帝国/
│   ├── 概念/
│   ├── 人物/
│   └── 事件/
├── 目录.md
└── 日志.md
```

笔记沿用对应范本的 YAML frontmatter 和 Markdown 内容。`来源` 指向资料，`[[页面名]]` 表达笔记关联；网页需要分别解析这些字段和链接。原始资料由宿主保存并建立来源链接，不嵌入技能包。

## 来源定位

在已有 `来源` 字段之外，可增加 `来源定位` 列表，为每份实际使用的资料记录可验证的位置：

```yaml
来源定位:
  - 文件: 教材.md
    小节: "1.1 东亚的发展"
    原文起始行: 26
    原文结束行: 78
```

上面仅展示字段形式，示例值不能直接复制为真实引用。行号从 1 开始，指向实际读取的来源文件。

如果通过原 PDF 或可靠的解析映射验证了页码，再添加 `PDF起始页`、`PDF结束页`；页码从 1 开始，表示 PDF 文件中的物理页序号。印刷页码如需展示，应另行记录，不能混用。只写有依据的字段；没有页码映射时省略 PDF 页码，并在完成报告中说明。

此字段支持笔记级来源定位。逐段或逐句引用需要正文中的引用标记与对应位置记录，不能把整篇笔记的来源范围当成每个论断均已核对。只有原始 Markdown 的行号时，也不能推断出 PDF 页码。

## 宿主负责的工作

网页提供「History 教材整理」与「手动编写／导入 Markdown」两个入口；后者不启动 Agent。后端负责接收文件、准备上述输入、启动任务并保存状态；PDF 工具负责提取内容及页码；Agent 使用技能生成笔记；网页展示结果和可解析的引用。

这是接入约定，当前技能包不表示这些网页入口、解析工具或后台任务已经实现。

# History 教材整理

按照老师已有的整理规则，把指定资料转为彼此关联、能够追溯来源的历史笔记。

## 开始处理

1. 读取 [老师的原始规则](references/author-rules.md)，执行其中的语言、资料整理、目录和日志要求。问答与整库维护只在任务要求这些工作时执行。
2. 读取 [输入与输出约定](references/input-output.md)，确认资料文件、输出目录和本次处理范围。网站调用时由后端提供这些参数；缺少资料或输出目录时先说明缺少什么。
3. 读取指定输出目录中已有的 `目录.md` 和 `日志.md`，再按需要读取相关笔记，避免重复导入。新知识库不存在这些文件时，在输出目录中建立。
4. 同一份资料同时提供 PDF 与对应 Markdown 时优先读取 Markdown，核对版式、图表或页码时读取 PDF。仅提供 PDF 时，需要实际可用的文本提取、OCR 或视觉工具；无法读取的内容应报告，不能猜测转换结果。

## 分批整理

- 按用户指定的章节或 Unit 处理。整本教材按 Unit 分批，每批结束后更新目录和日志；明确报告尚未处理的范围。
- AP 教材沿用 Unit 1–9 的章节结构。其他历史教材保留原有章节编号和标题，不强行编造成 AP 单元。
- 先建立主题页，再按老师规则抽出重要的国家、概念、人物和事件；已存在的实体更新原页。
- 根据页面类型读取并使用对应范本：
  - [主题](assets/templates/主题范本.md)
  - [国家与帝国](assets/templates/国家与帝国范本.md)
  - [概念](assets/templates/概念范本.md)
  - [人物](assets/templates/人物范本.md)
  - [事件](assets/templates/事件范本.md)
- 保留范本中的中文字段、英文 `aliases`、`[[双向链接]]`、补充和存疑区块。原始规则和范本作为只读输入使用。
- 来源位置按输入与输出约定记录。资料没有保留 PDF 页码时，使用可验证的章节或 Markdown 行号，并说明 PDF 页码尚未建立映射。

## 完成一批后

- 更新 `目录.md`，每条记录包含页面链接和一句话说明。
- 在 `日志.md` 追加实际处理日期、来源文件、章节范围及新增或更新情况，沿用 `- [日期] 动作 | 说明` 格式。
- 核对本批输出的分类、英文别名、来源及内部链接；链接可按文件名、相对路径或已有别名解析。计划中尚未生成的目标应列出，不把它们描述为已存在页面。
- 确认内容中的补充知识与资料原文已区分；不把推测的页码、原文位置或历史关系当成已验证事实。
- 最后说明本次处理范围、生成或更新的文件、未处理部分、待解决的链接或来源问题。只报告实际完成的步骤。

本技能提供整理规则与输出约定。PDF 解析器、后台任务、Codex 调用和网站展示由宿主程序提供；本文件本身不执行这些服务。

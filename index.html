// 03 控制台

一条命令，唤醒整个工作间

ForgeOS 的每一块能力都可以用命令召唤。forge run 之后， 学习、编码、记录、复盘会像子系统一样协同运转。

  • 统一入口：知识与代码共享同一个工作台
  • 按需挂载：模块可插拔，不用的绝不打扰
  • 数据留痕：每天的锻造都会沉淀成进度
forge — bash — 80×24
$ forge init my-workspace
$ forge add study-assistant knowledge-base
$ forge run --mode=deep-work

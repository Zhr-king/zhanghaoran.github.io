# ForgeOS 页面规划

当前网站包含首页展示和 `/planner/` 动态时间规划交互原型。首页提供首页、模块、控制台演示和关于四个区域；任务引擎入口已更名为“动态时间规划 / Dynamic Time Planning”。导航和搜索引擎站点地图只链接现有内容。

| 分类 | 当前入口 | 后续页面 | 内容就绪条件 |
| --- | --- | --- | --- |
| 首页 | `/#home` | `/` | 保留精简介绍和主要入口 |
| 动态时间规划 | `/planner/` | 已建立交互原型 | 本地规则识别任务、七天排程、固定安排、冲突提示、确认与重排；尚未连接 AI 智能体 |
| 系统模块 | `/#modules` | `/modules/`，以及学习、代码、笔记、任务、灵感、面板六个详情页 | 每页需有真实说明、使用流程及可用入口 |
| 控制台 | `/#console` | `/console/` | 有可实际使用的控制台后再开放 |
| 文档 | “文档筹备中”提示 | `/docs/`、`/docs/quick-start/`、`/docs/cli/`、`/docs/faq/` | 依据真实产品和 CLI 整理，避免虚构命令或操作步骤 |
| 关于 | `/#about` | `/about/`、`/about/changelog/`、`/about/contact/` | 更新日志依据真实发布记录；联系方式由站主提供 |

先完善现有单页的可读性和交互，再逐步增加有实质内容的页面。新页面上线时一并更新导航、canonical、分享信息和 `sitemap.xml`。

中英文保留简短的独立文案，默认英文并记住访客选择。语言按钮与主题按钮继续并排；不将导航改为只有图标的形式。

动态时间规划是第一阶段。后续围绕“动态时间规划、知识检索、个人工作流管理”三个核心能力逐步整合现有展示模块。规划原型的规则引擎位于 `assets/js/planner-core.js`，界面及本地存储在 `assets/js/planner.js`；未来接入智能体时保留“建议 → 用户确认 → 应用”的边界。当前按整段任务、每天相同可用时段安排未来七天，不支持重复日程、任务拆分、外部日历同步或跨设备同步。

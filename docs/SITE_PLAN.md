# ForgeOS 页面规划

当前网站是单页展示，已提供首页、模块、控制台演示和关于四个区域。下表的独立页面是后续规划，不代表功能已经上线；导航和搜索引擎站点地图只链接现有内容。

| 分类 | 当前入口 | 后续页面 | 内容就绪条件 |
| --- | --- | --- | --- |
| 首页 | `/#home` | `/` | 保留精简介绍和主要入口 |
| 系统模块 | `/#modules` | `/modules/`，以及学习、代码、笔记、任务、灵感、面板六个详情页 | 每页需有真实说明、使用流程及可用入口 |
| 控制台 | `/#console` | `/console/` | 有可实际使用的控制台后再开放 |
| 文档 | “文档筹备中”提示 | `/docs/`、`/docs/quick-start/`、`/docs/cli/`、`/docs/faq/` | 依据真实产品和 CLI 整理，避免虚构命令或操作步骤 |
| 关于 | `/#about` | `/about/`、`/about/changelog/`、`/about/contact/` | 更新日志依据真实发布记录；联系方式由站主提供 |

先完善现有单页的可读性和交互，再逐步增加有实质内容的页面。新页面上线时一并更新导航、canonical、分享信息和 `sitemap.xml`。

中英文保留简短的独立文案，默认中文并记住访客选择。语言按钮与主题按钮继续并排，主题在小屏上使用图标；不将导航改为只有图标的形式。

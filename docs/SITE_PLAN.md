# ForgeOS 页面规划

当前网站包含首页展示、`/planner/` 动态时间规划及 `/knowledge/` 学习知识库前端。首页提供首页、模块、控制台演示和关于四个区域；任务引擎入口已更名为“动态时间规划 / Schedule”。导航和搜索引擎站点地图只链接现有内容。

| 分类 | 当前入口 | 后续页面 | 内容就绪条件 |
| --- | --- | --- | --- |
| 首页 | `/#home` | `/` | 保留精简介绍和主要入口 |
| 学习知识库 | `/knowledge/` | 已建立会话前端 | 左侧历史、右侧聊天、底部输入；支持会话切换、搜索、重命名和删除，科目与文档弹窗、本地笔记检索及复习；初始无科目和会话；尚未连接 Obsidian vault 或 AI |
| 动态时间规划 | `/planner/` | 已建立交互原型 | 主页面待办直接写入 Google 日历、重叠标红；本地规则识别任务、七天排程、固定安排、冲突提示、确认与重排；尚未连接 AI 智能体 |
| Google 日历 | `/planner/calendar.html` | 已建立页面和本地连接服务 | OAuth + 标准 Calendar API，支持个人账号，无需 Workspace 订阅；填写时间、事件和备注后录入，重叠也创建并将新事件标红；需配置 Google OAuth，真实账号待验证；尚未接入 AI 理解 |
| 智能体账号 | `/planner/agent.html` | 已建立前端交互页 | Codex、Claude、Gemini、DeepSeek V4、Kimi 的演示登录、默认选择与退出；状态仅本机保存，未接入真实授权及调用 |
| 系统模块 | `/#modules` | `/modules/`，以及学习、代码、笔记、任务、灵感、面板六个详情页 | 每页需有真实说明、使用流程及可用入口 |
| 控制台 | `/#console` | `/console/` | 有可实际使用的控制台后再开放 |
| 文档 | “文档筹备中”提示 | `/docs/`、`/docs/quick-start/`、`/docs/cli/`、`/docs/faq/` | 依据真实产品和 CLI 整理，避免虚构命令或操作步骤 |
| 关于 | `/#about` | `/about/`、`/about/changelog/`、`/about/contact/` | 更新日志依据真实发布记录；联系方式由站主提供 |

先完善现有单页的可读性和交互，再逐步增加有实质内容的页面。新页面上线时一并更新导航、canonical、分享信息和 `sitemap.xml`。

中英文保留简短的独立文案，默认英文并记住访客选择。语言按钮与主题按钮继续并排；不将导航改为只有图标的形式。

动态时间规划是第一阶段。后续围绕“动态时间规划、知识检索、个人工作流管理”三个核心能力逐步整合现有展示模块。规划原型的规则引擎位于 `assets/js/planner-core.js`，界面及本地存储在 `assets/js/planner.js`；未来接入智能体时保留“建议 → 用户确认 → 应用”的边界。当前按整段任务、每天相同可用时段安排未来七天，不支持重复日程、任务拆分或跨设备同步；已支持添加任务时单向写入 Google 日历，尚未实现双向同步。
